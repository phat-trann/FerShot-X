# A46: Standalone Native Application Services Crate

Implemented standalone Rust crate `ferby-application-services` under `src-tauri/crates/application-services/`:

1. **Autostart Services**: Defines serializable `LoginState { enabled, supported }`, `login_state`, and `set_launch_at_login` leveraging pinned `tauri-plugin-autostart = "=2.7.0"`. Autostart mutations are strictly gated to packaged `.app` bundles via `is_packaged_app`.

3. **macOS 12 Compatibility**: Flagged transitive `smappservice-rs` (macOS 13+) in `auto-launch 0.6.0`; macOS 12 compatibility relies on the `LaunchAgent` plist backend without raising minimum OS baseline.
