# A39: Print preview explicit action checks

Scoped RTL/jsdom tests in `src/testing/antigravity-print-preview.test.tsx` verify public action invariants for `Workspace.print.tsx`:
1. No print action fires on load; the print button remains disabled until the supplied image finishes loading, and native dialog opens only upon an explicit user click.
2. When the native print request fails, an alert is surfaced without bricking the UI, and the print button remains enabled for immediate user retry.

All native transport functions (`readPrintPreview`, `requestPrintDialog`, `closePrintPreview`) are mocked; no real OS print or window APIs are invoked. No native acceptance or original parity is inferred.
