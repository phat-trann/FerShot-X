# FerShot X 1.5.0

- Add opt-in native Live Text to Library image previews on supported Macs with macOS 13+. Select text directly and copy with ⌘C or the native context menu.
- Keep native wheel/pinch zoom and two-finger pan in Live Text mode. Restore the regular Library preview when disabled; changing images cancels the prior request.
- Bound image size/concurrency, keep analysis in memory and hide the native view under confirmation dialogs/loading overlays. No extracted text is sent to the renderer or application logs.
- Fix a Record Area guide exclusion gap by creating guides before capture filtering, requiring an own-app exclusion while guides are visible and checking exact guide frames at the top edge.

The minimal VisionKit Swift bridge is the only exception to the Rust native implementation policy. macOS 12 retains runtime availability gating and weak framework linkage. Signing identity, updater keys, ARM-only releases and user credentials/permissions remain unchanged.

Automated checks use generated media, pure native geometry and injected IPC; installed Live Text selection/Copy/physical gestures, older-system launch and guide-free Record Area output remain manual acceptance. See live-text-manual-acceptance.md and video-manual-acceptance.md.
