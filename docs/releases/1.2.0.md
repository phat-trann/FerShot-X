# FerShot X 1.2.0

This release consolidates the interface updates developed after 1.1.10. The development candidate numbered 1.1.11 was not published separately.

- Shared rounded controls, consistent dark surfaces, system typography and compact Settings layout.
- Immediate Settings persistence, seven shortcut recorder rows and clearer inline utility actions.
- Full Edit workspace, compact Resize controls, flat tools and aligned shortcut hints.
- Restored editable Blur rendering when reopening Local drafts.
- Library bulk history removal, stable preview metadata and matched preview footers.
- Centered window presentation on the display under the pointer, preserving image-appropriate Edit sizing.
- Updates provides an explicit single action to download, install and restart, retaining signed verification, operation guards and retryable errors. Automatic checks never install updates.

All displayed product versions and package metadata use 1.2.0. Existing main-push release detection, updater public key, certificate configuration and no-notarization policy remain unchanged.

## Verification

Release checks cover TypeScript, 453 unit tests, 114 injected browser cases, native compilation with warnings denied, pure native geometry tests, version consistency and release-version detection. Browser tests use injected native APIs; they do not perform real captures, server operations or update installation.

Existing features retain their user-reported acceptance. Real multi-display placement, retained WKWebView drawing and delivery of native update notifications remain manual checks. GitHub release CI independently verifies the configured application certificate and signed updater artifacts before publishing.
