# FerShot X 1.1.2 verification candidate

Removes retired Print and Pin native backends, windows, capabilities, IPC wrappers and their dedicated tests. Removes five unreferenced inline Settings/color/window-appearance wrappers. The app has supported only Edit, Library and Settings routes; these retired windows were already unavailable. The Pin-only encoded-image clipboard helper and unused Print store initialization are removed.

Window activation now requests normal activation options rather than the deprecated ignoringOtherApps flag. The normal method remains supported by the macOS 12 baseline; real foreground/scroll capture behavior still needs manual verification. See [Apple activation API](https://developer.apple.com/documentation/appkit/nsrunningapplication/activate(options:)). No dependency upgrades or warning suppressions were added. CI now enforces warnings-as-errors for the production native library.

Thirteen retired files were archived and byte-verified before removal. Inventory, original hashes, source commit and archive hash are in docs/maintenance/C100-retired-files.json. The archive stays ignored under artifacts/archive; Git history and immutable review evidence remain preserved. Shared helpers with remaining consumers remain intact.

Validation: 441 unit tests, 64 injected native tests and TypeScript passed; production Rust compilation with -D warnings passed without warnings. Dedicated retired feature tests account for the decrease from 446/66. No real OS capture, FTP, permissions or update installation was automated. No new local release bundle was produced; CI builds versioned distribution assets.

Manual regression: open Library/Settings/Edit, use normal capture, scroll capture and Copy/Save/FTP, and verify foreground restoration. Existing 1.1.1 checklist remains relevant. Native acceptance stays 85% before/after.
