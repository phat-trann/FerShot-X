# FerShot X 1.1.1 verification candidate

- Scrolling capture accepts positive Accessibility trust when CoreGraphics event preflight disagrees. Genuine denial explains re-granting access to the installed app; ad-hoc upgrades may change macOS trust identity.
- Updates has its own Settings tab. Tray Check for Updates opens it and starts checking; download/install/restart remain explicit.
- Saved global shortcuts restore at startup. Install Shortcuts and Remove Shortcuts update registrations and persisted settings together, with rollback and cleanup handling.
- Settings, FTP, Library and updater statuses distinguish success, warning, error and information through color and text.
- Library initially previews the first image on each tab, preserving manual selection during refresh. Preview loading no longer clears FTP deletion errors.

The previous 1.1.0 release build/signing succeeded, but publication failed because the action emitted API asset URLs. The pipeline now resolves these against the exact draft asset metadata, verifies artifact signatures, replaces latest.json with public download URLs and only then publishes. Seven regressions cover this normalization; no signature check is removed.

## Manual verification

1. Install/update the candidate, grant Accessibility to the installed FerShot X.app, quit/reopen, then scroll-capture a genuinely scrollable browser page. Confirm stitched output and Escape stopping. If denied, remove/re-add the installed app in Accessibility and report whether this resolves it.
2. Install capture shortcuts, quit/reopen, and use them without visiting Settings. Remove them, quit/reopen, and verify they remain removed. A competing app shortcut should show a conflict without losing saved settings.
3. Tray Check for Updates opens Settings > Updates and starts a single check. Verify current/available version, progress, explicit installation and restart with a later published version.
4. Verify green saved/success, amber warning and red failure states; errors remain readable and do not disappear during preview loading.
5. Open Library and switch FTP/Local: first image previews automatically; manually selected images stay selected on refresh.

Native permissions, real FTP and signed version-to-version installation remain user acceptance work. Acceptance remains 85%; passing injected tests is not a native/server acceptance claim.
