# FerShot X 1.2.1

- Separate Apple Silicon and Intel downloads reduce installed size by including only the required CPU binary. The updater retains its endpoint/key and selects the matching platform package. CI checks both signatures, certificates and CPU mappings before publishing.
- FTP previews cache recently viewed images in memory: up to eight entries, five-minute expiry and a 64 MiB encoded-plus-estimated-decoded budget. Switching images/tabs reuses cached data. Refresh invalidates the cache; removed or changed uploads cannot leave stale cached entries.
- Library combines overlapping metadata refreshes, avoids hidden-window periodic polling and skips unchanged thumbnail renders.
- Removes 51 disconnected legacy UI/workflow/test files after import checks and byte-verified archival. Active functionality and historical review evidence remain preserved.
- README now focuses on installation and user workflows, with developer setup separated and screenshot requests listed.

Local Blob reads are explicitly permitted by the desktop content-security policy for preview caching; arbitrary external renderer requests remain restricted. Version metadata is synchronized to 1.2.1. Existing 1.2.0 Universal release assets remain unchanged.

Automated checks use synthetic data and injected APIs. Installed Universal-to-thin updater transition, actual artifact sizes and native runtime behavior require version-to-version acceptance; signing/architecture publication checks run in GitHub Actions.
