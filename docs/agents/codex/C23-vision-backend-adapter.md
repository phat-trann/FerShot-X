# C23: Injected Vision backend adapter

Implemented a local C18 RecognitionBackend using injected source leases, language discovery and A33-shaped transport ports. Validates exact source/revision/dimensions/byte size, copies input bytes, bounds schema/counts/Unicode/aggregate UTF-8 and maps immutable text/QR outputs. Abort checks suppress dispatch and late results; valid resolver leases release once. QR IDs are deterministic revision/ordinal IDs scoped to the selected source result. No shared/native files or dependencies changed.

Local port uses Uint8Array; C08 must serialize bytes, authorize native commands, bind source identities and run blocking Vision work. A33 response has no source identity, so transport correspondence remains a trusted port obligation. Language aliases outside the C18/A33 syntax intersection fail explicitly. A33 performs actual image decoding. Port promises must settle; cancellation does not preempt synchronous native work.

Scoped functional test counts and global typecheck results are in the packet. Integration typecheck reports existing A37 unused import and P61 test fixture typing; no C23 diagnostics. No native OCR/clipboard/capture or app build was run. Formatting/lint delegated to Copilot H01.
