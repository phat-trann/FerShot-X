# Navigation Controls

Controlled React toolbar component for canvas viewport navigation:
- **Zoom Steps**: Stepwise zoom-in and zoom-out bounded between configurable limits (defaults: 25% to 400%).
- **Quick Presets**: 1:1 actual-size reset and viewport-fit actions.
- **Coordinate Mapping**: Complements `fitImage` from `src/features/viewport` and `mapClientPoint` from `src/features/point-map` for synchronized pan, zoom, and cursor coordinate translation.
