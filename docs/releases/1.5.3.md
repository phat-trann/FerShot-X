# FerShot X 1.5.3

Record Area again dims the screen outside the selected region. The dimming guide uses a single click-through window aligned to the selected display. It appears after recording starts and the capture filter excludes it. If the guide cannot be placed or excluded, the recording continues and logs the guide failure.

Stop, cancel and retry retain the existing recording workflow. Physical multi-display placement and guide-free video are part of [installed acceptance](video-manual-acceptance.md).
