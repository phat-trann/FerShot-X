# COORD11 shortcut adapter allocation

P97 adds an isolated typed canonical accelerator adapter to complete the existing C13 native-shortcut seam. Reuses the reviewed full-map preference validator and maps a documented W3C key-code subset; unsupported keys reject explicitly. Root owns native plugin parsing/registration and OS effects, worker owns a pure adapter plus scoped tests. Existing versions stay frozen; any new task-required native package must not replace existing locked package versions. No original shortcut equivalence is asserted.
