# FerShot X 1.3.0

## Editing

- Magnifier now has an editable source ellipse, a separate magnified view and a connecting line. Resize the source independently in either direction; move the magnified view around it. New magnifiers choose available space with a consistent gap.
- Source manipulation temporarily hides Magnifier output; dragging the magnified view keeps its contents and connector visible. Spotlight’s dimmed backdrop hides while moving.
- Counter pointers support continuous angle adjustment, and selection bounds follow the counter while dragging.
- Text edits directly on the image with a blank caret, compact padding and Shift+Enter for new lines. Enter commits; Escape cancels. Drafts, undo/redo and exported images preserve the text.
- Click the zoom percentage for a slider. A clickable Fit marker points to the exact fitting percentage and follows window resizing. The popup has compact spacing.

## Library

- Opening an image shows a spinner on its row and Edit action, with a preview overlay until Edit is presented. Duplicate requests are blocked; errors allow retry.
- The native handoff carries a temporary request token so unrelated window events do not end loading. Tokens are not saved in image drafts.
- Inbox requests arriving before the Edit event listener is ready are read after registration. Pending requests wait for active image operations.
- Library receives the first click while inactive on macOS, preserving single-click selection and double-click opening.
- Edit handoff errors retain operation and duration metadata without recording filenames, image contents or credentials.

Apple Silicon only. Existing updater keys, signing identity, permissions and stored credentials are unchanged. Automated checks use injected OS/network boundaries; installed Library activation/presentation and signed update behavior still need real-device verification.

Release verification: 426 unit tests, 73 injected browser cases, production renderer build and root Rust test-target compilation passed. Release-version, updater configuration, signing, publication-gate and manifest checks passed. Five older browser expectations were updated to match the new requested behavior before their successful rerun. CI handles signed application packaging and updater artifact verification.
