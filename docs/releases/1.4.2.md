# FerShot X 1.4.2

- Library Copy, Select All and Delete/Backspace work across the window, including preview and toolbar focus. Native macOS Copy events use the existing selection action.
- Zoom Local/FTP image previews with the mouse wheel, Command-wheel or pinch around the pointer; two-finger swipes pan. Focus the preview and press 0 for Fit, or +/− to zoom.
- Preview zoom uses the loaded image without refetching, re-encoding or changing the original/draft. Changing image or resizing resets to Fit.
- Preserve normal text editing, busy-operation guards, oldest-first FTP link order and explicit remote deletion confirmation.

Renderer compilation, unit tests and injected browser checks cover gestures, exact pointer anchors, preview cache and selection shortcuts. Existing signed ARM-only release/updater configuration is unchanged. Installed native Copy and physical trackpad behavior remain manual acceptance.
