# P50 Lifecycle and Exclusion Parity Cases

Added five bounded cases covering the deliberate F27–F29 network exclusions,
F30 shortcuts, F31 lifecycle preferences, F32 deep-link boundary, and F33–F34
licensing/telemetry exclusions. The cases use only the supplied brief and
app-preferences public exports.

Excluded cases remain explicitly `EXCLUDED`; other target and Ferby statuses
are `NOT_EXECUTED`, with null expected target results. No credentials, OS
bindings, URLs, licensing, telemetry, runtime or product code were used.
