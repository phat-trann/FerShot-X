# A44: Controlled Native Capture Action Controls

Implemented controlled interactive capture controls under `src/features/capture-action-controls/`:

1. **Component & Props**: Exports `CaptureActionControls` accepting `disabled`, `activeWindowSupported`, `fixedRegionSupported`, and `onAction: (action: CaptureActionId) => void`.
2. **Action Support**: Renders explicit buttons for all 8 capture actions (`fullscreen`, `area`, `window`, `active-window`, `fixed-region`, `repeat-region`, `scrolling`, `ocr`).
3. **Capability Gating**: Disables `active-window` when `!activeWindowSupported`, disables `fixed-region` and `repeat-region` when `!fixedRegionSupported`, and disables all buttons when `disabled === true`. Guarded click handlers forward each valid explicit click exactly once.
4. **Isolated Seam**: No OS screen capture APIs, global event listeners, or root wiring edits; designated for C26 integration.
