# A40: Archive panel explicit action checks

Scoped RTL/jsdom tests in `src/testing/antigravity-archive-panel.test.tsx` verify public action invariants for `ArchivePanel.tsx`:
1. When `imageCount` is 0, the export button is disabled; import remains available, and callbacks trigger only on explicit user click with zero render side effects. Supplying `imageCount > 0` enables export.
2. When `busy` is true, import and export are locked, while the cancel button is enabled and invokes `onCancel` on explicit click. Status and error banners render only when non-null.
