# FerShot X 1.2.2

- New releases target Apple Silicon only. Intel build/toolchain steps are removed; CI verifies ARM64 app identity, certificate, manifest target and signed updater archive before publication. Older Intel/Universal assets remain available unchanged.
- Opening Settings now presents only its window instead of unhiding other retained app views. Existing centered placement and window dimensions remain.
- Edit’s delete tool is labelled Delete.
- Current/New version rows share aligned columns. The temporary development preview is removed; only real available updates appear.
- Open Logs Folder is an icon immediately after days on the retention row. Settings persistence and error handling remain unchanged.
- Folder and equivalent actions share consistent hover borders and enabled/disabled opacity. Tooltips align to device pixels and preserve wrapped controls’ refs, events, accessibility descriptions and shortcuts.
- Regression guards prevent ordinary feature controls from restoring accent hover borders; specialized Edit, recording and semantic action states retain their intended behavior.

The permission flow is unchanged. No first-launch permission setup was added.

Validation includes TypeScript, the full 419-case unit suite, cross-window browser regressions and ARM/signing/manifest tests. Native Settings isolation and signed update behavior still require installed verification. GitHub CI performs release packaging/signature checks; local automated results do not constitute real OS/server acceptance.
