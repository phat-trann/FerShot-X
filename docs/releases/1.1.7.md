# FerShot X 1.1.7 verification candidate

- FTP and HTTP preview passwords now use a native-only, bounded, atomically written local plaintext file with owner-only permissions (0600). Stored passwords are never returned to the renderer or put in process arguments/logs. Existing profile settings and queued destinations are preserved. Files can be read by the current macOS user; this is not encrypted storage.
- Runtime Keychain access and automatic legacy Keychain import are removed. **Re-enter FTP and HTTP passwords once in Settings → Uploading after updating.** Existing Keychain entries are neither read nor modified. App/updater signing keys and certificate configuration are unchanged.
- Capture preparation masks and clears retained Edit canvases before native capture hides the view, with a bounded compositor wait. New-document presentation replaces the masked editor; cancellation repaints retained pixels/elements. Obsolete pending presentation callbacks are invalidated before another capture.
- Fastest settling delay decreases from 250 to 100ms; Fast from 400 to 250ms. Frame acquisition/encoding still takes time. Existing movement/overlap/size checks and explicit partial-result warnings remain.
- Context cursors distinguish selection, drawing, text placement, counter placement, magnification, dragging, resizing, sliders, disabled controls and image-operation loading. Gesture semantics remain unchanged.
