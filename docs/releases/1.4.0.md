# FerShot X 1.4.0

Screen recording and video editing are now available alongside screenshots.

- Record a screen or selected area on macOS 15+, with optional system/microphone audio and mouse metadata.
- Edit video with compact layered timing, trim, split, duplicate, hide/lock, undo and magnetic alignment. Add highlights, arrows, text, covers and image layers.
- Save/copy edited MP4s, upload through FTP and reopen Local video drafts. Immediate Upload also supports recordings.
- Configure separate Screen, Area and Stop recording hotkeys; existing assignments migrate automatically.
- Library opens centered at 75% of the active display work area; Video Edit uses 80%, Image Edit follows image size and Settings stays fixed.
- Improve recording finalization/recovery, loading feedback and integer timestamp handling. Preserve ordinary tray icon/menu behavior and native macOS recording controls.
- Remove unused video adapter exports, duplicate cursor CSS and redundant dependency declarations.

The existing Apple Silicon signing/updater workflow publishes this version after a normal main push. No certificate/updater-key, credential or permission changes. Recordings are limited to 30 minutes and 1080p/30fps; remote re-edit uses flattened media. Audio/cursor/recording behavior on installed macOS remains covered by the manual acceptance checklist in video-manual-acceptance.md. Automated checks use generated media and injected IPC only.
