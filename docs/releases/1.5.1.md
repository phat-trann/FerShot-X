# FerShot X 1.5.1

- Live Text uses one zoomable image in Library. The button stays in place while images load, and native view teardown waits for AppKit gesture tracking to finish.
- Capture and new recording shortcuts are blocked while a recording starts, runs or finishes. Stop Recording remains available. Local retention protects recordings queued for Edit or in use by Edit and Library previews.
- Edit saves Local images and drafts together. If a draft fails to save, the editor keeps it open for retry. Completed edits release image resources when closed or replaced.
- Library loads Local images, recordings and FTP history independently. An updated draft refreshes its preview. Unrelated refreshes preserve video playback and the FTP preview cache.
- Video Edit respects locked annotations. FTP upload continues even if the link cannot be copied, and an active upload blocks deletion of the same queue item.
- Diagnostics include failed operations and the originating app version, build and time for imported macOS crash reports. Image content, recognized text and credentials are kept out of diagnostic records.

Apple Silicon. Automated verification uses generated media and injected IPC. Installed recording, FTP and Live Text gesture checks remain pending. [Source review fixes](../agents/codex/C182-review-fixes.md)
