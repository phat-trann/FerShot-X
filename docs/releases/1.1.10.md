# FerShot X 1.1.10

## Changes

- macOS updater notices use modern UserNotifications with real authorization and submission callbacks. The previously pinned legacy backend returned success before the eventual send and unconditionally reported granted desktop permission. This explains missing error visibility, not a proven diagnosis of the installed machine's OS delivery failure. The existing locked objc2-user-notifications 0.3.2 is used directly; no package version upgrades or Swift. Capture-completion notifications/non-macOS fallback retain the existing Tauri plugin.
- A retained delegate requests foreground Banner/List presentation, handles only default clicks on the app's update/test identifiers, and opens Updates on the main thread. Worker waits are bounded; denied, timed-out and rejected requests remain retryable and receive specific error-only diagnostic codes. OS submission acknowledgement is not a guarantee that Focus/notification settings display a banner.
- Settings → Updates adds Test Notification and clear sending/submitted/denied/failed/unavailable status. The test explicitly identifies itself as a test, never invents an available version, and does not download/install/restart. Successful real update versions remain deduplicated per process. Startup/daily checks and explicit install/restart are unchanged.
- Wheel/modifier-wheel and pinch zoom keep the document point beneath the cursor fixed, including when the image fits the viewport. Camera changes remain frame-batched; two-finger pan still pans. Fit and new images reset the camera. Offsets affect viewing only, never saved coordinates/drafts/output.
- Arrow shafts end at the head base with flat caps; heads are filled once, without an extra outline or a shaft projecting through the tip. Head depth is bounded by arrow length. Preview, live endpoint manipulation and exports share geometry.

## Verification

Existing features retain 100% USER_REPORTED acceptance. Installed 1.1.8/public 1.1.9 and the missing notification were verified from app metadata/public release state/user feedback; no private identities or user image data were read. These new changes require manual retest.

1. Install 1.1.10 using Settings → Updates. Use Test Notification, answer macOS's authorization prompt, and click the test alert to open Updates. If denied, enable FerShot X manually in System Settings → Notifications and retry. No additional release is needed to test this button. A later available version is still needed to verify the automatic updater-notice path.
2. Zoom in/out over off-center image points, then blank margins; repeat with mouse wheel, modifier-wheel and touchpad pinch. The anchored point should stay under the pointer. Pan, Fit and opening a different image must remain correct.
3. Draw thick/short/diagonal/reversed arrows, drag endpoints, undo/redo, Copy/Save/Upload and reopen a Local draft. The tip stays sharp, no shaft projects beyond it, and output matches preview.

No real notification, OS capture/input, server action, update installation, credential/Keychain or permission mutation was automated. App/updater signing keys and CI certificate policy are unchanged. API references: [Apple authorization](https://developer.apple.com/documentation/usernotifications/unusernotificationcenter/requestauthorization(options:completionhandler:)), [Apple UserNotifications](https://developer.apple.com/documentation/usernotifications/unusernotificationcenter).

Source checks passed: 434 unit tests, 77 injected native tests, all 77 browser regressions, production frontend build including TypeScript, native production compilation with warnings denied and version consistency. Browser cases check cursor anchoring within 1.5 CSS pixels, Fit recentering, sharp arrow pixels in canvas/export and denied/successful notification states through injected IPC. Real macOS notification delivery is not claimed.
