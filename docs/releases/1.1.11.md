# FerShot X 1.1.11

Historical development candidate, consolidated into release 1.2.0. The checks and publication restrictions below record each implementation checkpoint. Follow-up fixes align all settings switches label-left/control-right and consolidate Settings top insets, form spacing and rounding. Earlier automated evidence below describes C110; C111 records the follow-up checks separately.

All interface controls now use the shared UI library, including previously direct buttons, color/file inputs, radio controls and updater progress. Form callbacks, native validation, refs, keyboard handling and IPC payloads remain compatible.

The interface uses `system-ui, -apple-system, BlinkMacSystemFont, sans-serif`. Shared tokens define 32px form controls, 12px control rounding, 20px panel rounding, 8px field gaps, 16px form spacing and one typography scale. Existing white/silver text, dark surfaces, blue accent and thin selected borders remain. Canvas handles, pill switches and the fixed editor status strip retain their specialized geometry. Annotation typography/export pixels are independent.

See [interface system](../design/INTERFACE.md) for reusable components, tokens and conventions. A source guard prevents direct form controls outside the UI library.

Existing features remain 100% USER_REPORTED accepted. Manually check the new appearance in Settings, Library and Edit, particularly FTP form layout, tool overflow and contextual controls. Native update notification delivery remains a separate pending check; this release does not claim it passed.
