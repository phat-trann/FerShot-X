# FerShot X 1.0.0 — source candidate

This source candidate assembles the completed screenshot, editing, Library, preferences and explicit FTP workflows. Product version is synchronized from package.json. The current Konva/draft native changes have not been built at the user's request; an older internal bundle does not represent this source. This is not a notarized public distribution or a claim of bug-free native/server acceptance.

## Changes

- One compact, keyboard-accessible React Konva editor toolbar/canvas for drawing, crop/resize/effects, composition, color and output. Crop/Resize/Blur are drafts until Enter; Escape cancels. Undo/redo shares one drawing history. Native PNG dragging remains available from the toolbar.
- Native region selection followed by automatic downward scrolling, ending on Escape, unchanged pixels or resource limits. Alignment failure is reported rather than publishing a corrupt stitch. Input-event and Screen Recording permission may be required.
- Separate Library, Edit and Settings windows. Local retains one stable entry plus editable vectors through raster derivatives and reopen; output actions do not overwrite its draft with flattened pixels. Search is removed. Edit uses a 16:9 content aspect and an image-appropriate size within 80% of the current display work area. Closing the last image hides Edit. Captured-image Copy/Save/Upload hides it after successful output or queue submission.
- FTP-first Library with a 25% sidebar, relative paths, visible selected tab, lazy bounded thumbnail caching and HTTPS full previews. Successful uploads retain thumbnails only; failed/pending jobs retain frozen retry pixels. Permanent server deletion requires a confirmation dialog. Removing history is a separate local action.
- Lucide-only active toolbar/menu glyphs (80% geometry, doubled stroke) and the original uploader symbol in a padded, bordered app icon. Removed external links, tray Edit, tonal adjustment, Measure and manual scrolling. Retired source and obsolete navigation tests were archived with hash manifests before removal.
- Independent encrypted Keychain credential storage, frozen predicted URLs/retries, configurable naming, 30-day single-entry editable Local drafts, error-only diagnostics and startup settings from the preceding completed integration work are included. Earlier contributor identities and immutable review records remain intact.

## Native and server verification still required

1. Start the built app: Library opens first; Settings stays independent. Verify the Lucide tray items, Command-Q, close-to-hide and Dock reopening.
2. Capture Area, Repeat Area, screen and each window mode; cancel/Escape and denied permission must restore the previous views. Check small and large images, Retina displays and a second monitor for 16:9/80% sizing and Fit.
3. Select a scrollable desktop region; confirm content scrolls and stitches, Escape returns the collected result, and reaching the bottom ends capture. Verify input-permission failure, animated content and fixed-header failure behavior. Original runtime algorithm equivalence has not been established.
4. With your configured server, Upload from an edited capture: confirm the immediate predicted URL, successful transfer and HTTPS image. Retry a failed upload after restart; its path, URL and image must stay unchanged. Successful jobs should retain only a thumbnail in ftp-v1.
5. Select an uploaded image in Library, open Edit, then explicitly confirm permanent deletion. Verify both server removal and local history refresh. Test denied deletion and lost connection without assuming the server file still exists. Automated checks never contact your server.
6. Copy, Save (including Cancel) and Upload from captures; verify only successful actions hide Edit. Verify log retention/folder opening, Keychain persistence and autostart through normal user actions.

The acceptance ledger retains outstanding real-server, credential/restart and integrated-native gates. Source publication does not silently mark these gates passed. Future accepted fixes use patch versions; compatible feature releases use minor versions, with a new summary and scoped commit/push.
