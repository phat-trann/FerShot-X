# A74: F01 Visual Area-Selection Producer

Delivered the visual area-selection producer component `CaptureRegionSelector` for Codex C35 integration:

1. **Coordinate Mapping & Clamping**: Employs `mapClientPoint` to translate viewport pointer drag events into bounded source-pixel coordinates, clamping values to source image dimensions (`image.width`, `image.height`).
2. **Numeric Precision Inputs**: Provides synchronized manual integer inputs (X, Y, Width, Height) for exact pixel adjustments alongside pointer drag selections.
3. **Controlled API Contracts**: Exports `CaptureRegionSelectorProps` accepting caller-provided `ImageDocument`, `busy` flag, explicit `onConfirm({ x, y, width, height })`, and `onCancel()`. Does not auto-capture or revoke image URLs.
4. **App Styling**: Styled via `CaptureRegionSelector.css` with responsive container, crosshair cursor, visual highlight overlay, and accessible buttons.
