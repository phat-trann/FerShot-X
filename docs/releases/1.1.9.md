# FerShot X 1.1.9

Existing features are **100% USER_REPORTED accepted** by explicit user confirmation on 2026-11-12. Native update notification delivery/click remains a separate pending check. This is not a claim of exhaustive bug-free behavior or automated macOS performance acceptance.

## Performance

- Window routes load independently. Library and Settings no longer initialize the Konva editor. Production dependency closures: Library 585,092 bytes, Settings 493,426 bytes and Edit 753,786 bytes, compared with the prior shared 975,329-byte JavaScript bundle. This reduces JavaScript needed for those routes by approximately 40%, 49% and 23%; initial bootstrap/static dependencies are 274,047 bytes. Shared chunks remain cached. These are bundle bytes, not measured app-launch speedups.
- Presentation resets visible canvas backing surfaces once, retaining synchronous/deferred recovery paints through 400ms. The same synthetic scenario measured 24 canvas-width resets before and 4 after, with four visible layers (83% fewer resets). Late-loss recovery and unchanged zoom remain covered.
- Edit no longer polls/list-transforms unused Local sidebar metadata. Draft writes coalesce queued superseded revisions and skip unchanged immutable snapshots. Awaited saves still wait for the latest queued draft; failed saves retry with pixels. Library remains responsible for listing and native cache operations preserve expiry.
- Empty Local drafts preview the existing PNG directly, avoiding a decode/render/PNG re-encode. Annotated previews still render the saved draft; renderer code loads on demand. Library row sorting and date formatting are memoized and reuse one formatter.

## Cleanup

Removed the isolated retired LibraryPanel implementation, CSS, barrel and its three dedicated legacy test files: six files, 46,037 bytes, 1,502 lines. Each was reference-checked and archived byte-for-byte in ignored tmp/retired-C108 before deletion; per-file hashes are in docs/cleanup/C108-retired-library.json. Removed unused sidebar DTO/open/store wrappers and the constant legacy editor-mode branch. Preserved author history, immutable reviews/research and all user images, credentials and settings.

Twelve unit cases belonged exclusively to retired UI. Four new draft persistence regressions cover write coalescing, no background metadata polling, failed-write retry and awaited latest-draft completion. The active browser suite retains current Library/editor behavior. The IPC test fixture now clones FTP results like native serialization; it no longer relies on unrelated Local state changes to display externally mutated mock objects.
