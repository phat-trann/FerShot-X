# A43: Bounded Recognition Preference Codec

Implemented the isolated version-1 recognition preferences codec under `src/features/recognition-preferences-codec/`:

1. **Schema & Types**: Exports `RecognitionPreferences`, `RecognitionMode` (`"ocr" | "qr" | "both"`), and `RecognitionPreferencesSidecarV1` envelope (`version: 1`).
2. **Strict Validation**: Bounds UTF-8 payload to 16 KiB (16,384 bytes). Enforces exact allowed fields, disallows type coercions, and validates/deduplicates language tags (capped at 16) using `validateOcrLanguages`.
3. **Explicit Ferby Defaults**: Defines `DEFAULT_RECOGNITION_PREFERENCES` as explicit Ferby choices (`mode: "both"`, `languages: ["en-us"]`, `preserveLineBreaks: true`), distinct from Shottr defaults.
4. **Isolated Scope**: No native framework calls, UI, or filesystem side effects.
