# C47 — Native explicit FTP publisher

Source reference: user-owned `../upload-screenshot/src/main/uploader.ts`, `queue.ts`, `pathUtils.ts` and `shared/types.ts`. Public URLs retain the old mapping: base URL + absolute remote directory + encoded filename. New filenames use a high-resolution allocation ID instead of repeating day/time names; this avoids month/retry collisions. Enqueue has no network or watcher/stability wait. It validates/rasterizes the edited PNG, saves a private retry snapshot and fixed target, then returns the URL. Start is separate; four concurrent starts maximum. Retries preserve the original endpoint/settings/path/bytes. App launch marks interrupted transfers failed and never automatically reconnects.

Settings JSON contains no password. Native macOS generic-password Keychain storage uses an account bound to host/port/user; changing settings cannot redirect queued jobs. System `/usr/bin/curl` receives credentials only through stdin config, disables curlrc/proxies, restricts FTP, has connection/overall timeouts and optionally requires TLS. No shell, credential argv, transport stderr logging, remote deletion or original-file mutation. See [curl manual](https://curl.se/docs/manpage.html) for FTP/create-dirs, protocol and config behavior. Data is private 0700/0600, queue bounded at 256 entries/512 MiB retry storage; corrupt queue is preserved.

Actual Keychain and real FTP server transfer remain unexecuted; no credentials or server were accessed. Formatting/lint delegated to Copilot H01. Frontend integration follows in C48.
